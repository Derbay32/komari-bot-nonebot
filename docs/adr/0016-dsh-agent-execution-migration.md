# 将群聊 Agent 执行迁入 DSH 并退役自有模型网关

项目将聊天回复的 Agent 执行迁入 DeepSeek Harness（DSH）。
项目将群聊总结的 Agent 执行迁入 DSH。
DSH 直接请求模型服务。
项目完整退役 `llm_provider` 插件。
项目完整退役 `agent_run_logger` 插件。
迁移目标是消除自维护 Agent loop 的成本。

DSH 统一管理聊天回复与群聊总结的模型连接配置。
连接配置包括 API 地址、凭据、模型名与请求协议。
项目配置表不维护第二套模型连接定义。
项目管理 API 提供模型配置的后台管理入口。
管理入口不在 PostgreSQL 维护另一份模型连接定义。

聊天与总结的系统提示词交给 DSH 管理。
现有管理 API 转接对应提示词配置操作。
Python 不维护第二份生效提示词。
业务开关与 Jev 判定提示词保留现有管理方式。

本次不增加 DSH 图形管理界面。
通过内部桥接调用 DSH 配置与凭据服务。
动态配置持久化到实际 profile 的 `cordis.patch.yml`。

dotenv 只保留现有的必要连接配置。
本次不新增 dotenv 配置项。
DSH 配置与凭据从首次设置起统一走管理 API。
模型选择支持后台修改。
凭据不写入受版本控制的普通配置。

聊天回复与群聊总结分别维护模型绑定。
新任务读取并冻结对应模型选择。
运行配置与凭据使用可写的持久化目录。
启动初始化不能覆盖后台已保存的配置。

除明确退役项外，本次保持现有群聊业务行为。
本次删除模型驱动的独立查询重写。
知识与帮助的字符串替换规则继续保留。
本次删除委托图片理解工具。
本次不将这两项辅助调用迁入 DSH。

本次不新增聊天模型的图片能力检测。
模型无法原生处理图片时，采用 DSH 的占位符行为。
运维通过提示词要求模型承认无法读图。
本次不恢复委托图片理解作为回退。

自动记忆召回使用短上下文与当前触发消息。
短上下文来自聊天 Redis 近期消息缓冲。
短上下文最多包含目标前 10 条同群近期消息。
自动召回不复用 Jev 的判定专用消息筛选。
查询保留明确的引用关系。

查询超出总预算时，优先保留当前消息。
更早的上下文优先退出预算。

自动记忆召回调用 Hindsight `recall`。
自动记忆召回不默认改用 `reflect`。
Agent 继续使用按需记忆查询工具。
按需查询使用 Agent 提供的查询文本。

本次保留现有知识库。
本次不把知识库迁入 Hindsight。

知识库自动检索直接使用当前消息原文。
知识库自动检索不拼入对话上下文。
知识库自动检索不改写查询文本。
现有知识库字符串替换规则不适用于原文查询。
独立的用户 UID 精确知识查询保持不变。

聊天回复使用专用聊天回复预设。
聊天回复只开放记忆检索、知识库检索与网页搜索查询。
网页搜索包含 search 与 fetch 两个工具。
群聊总结使用专用总结预设。
两个预设使用各自的系统提示词。
总结预设保留既有受限历史读取能力。

Python 只负责提供结构化的上下文数据。
上下文数据包含历史、记忆与知识库内容。
数据保留身份、引用关系、来源与信任级别。
Python 不拼接系统提示词或完整模型 messages。

DSH 侧管理工具说明与模型可见参数 Schema。
DSH 侧通过官方插件与预设机制组装模型输入。
初始任务数据组织成一条分区的 user 消息。
历史、记忆与知识库内容放入对应数据分区。

长期角色设定放入 Agent preset 的系统提示词。
不可信上下文不能提升为系统指令。
Python 继续承担业务工具、准入检查与回复履约。

历史分区保留说话者、消息身份、时间与引用关系。
历史 Bot 发言使用来源字段标明，不重建 assistant 回合。
禁止补造已阅读记忆这类 assistant 确认消息。
DSH 记录当前任务真实产生的 assistant 与工具历史。
单条初始消息不限制后续补齐或工具结果回填。

工具循环与会话历史使用 DSH 原生实现。
不迁移 `required` 与 `prompt_guided` 双模式配置。
普通模型文本只保留为本次任务的中间记录。
项目不另外实现裸文本历史删除逻辑。
本决定替代 ADR-0009 的双模式与裸文本历史规则。

最终聊天回复必须通过工具提交。
最终群聊总结必须通过工具提交。
模型直接输出的最终文本不能作为业务结果。
缺少有效工具提交时，系统不能回退为直接发送文本。
工具提交不绕过既有业务校验与平台履约流程。

保留独立的好感度提案工具。
模型自主决定好感度调整提案。
现有参数校验与调整范围继续生效。
好感度调整仍在确认回复送达后执行。

聊天完成条件包含有效的好感度提案与最终回复。
两项提交不要求固定顺序。
系统在缺少有效提交时提示模型补齐。
提前提交的最终回复只暂存，不触发平台发送。
两项提交齐备后，任务进入既有回复履约流程。
现有轮数与工具调用预算继续约束续跑。

本次不向模型开放 shell。
本次不向模型开放任意文件读写。
本次不向模型开放自主插件修改。

同一镜像交付 Python Bot、DSH 与接入插件。
同一容器运行 Python 与 DSH 两个独立进程。
DSH 进程长期运行，不为每条消息重新启动。
本次不部署独立 DSH 服务容器。
使用官方 DSH 依赖，不维护源码副本。

统一管理进程的启动、就绪与退出。
DSH 未就绪时阻止新生成任务进入。
配置与凭据使用持久化存储。
普通应用日志继续遵守既有部署策略。
本次不新增 dotenv 配置项。

每次聊天回复或群聊总结使用独立 DSH 内存会话。
同一任务的工具调用与补齐过程复用这个会话。
后续任务不继承这个会话的历史。
完成的回复或总结任务直接删除对应会话。
会话删除不授权清理历史 Agent Run 文件。

不支持 DSH 进程崩溃后恢复原任务会话。
用户接受这项中断风险。

任务尚未终止时保留对应会话。
任务内允许的重试复用当前会话。
任务取消后删除会话。
重试耗尽后，系统明确记录最终失败。
最终失败的任务直接删除会话。
系统不通过新建会话重启同一失败任务。

模型请求重试只使用 DSH 内置组件。
项目不在外围再包装重试器。

模型请求的自动重试只考虑暂时性上游故障。
允许评估的故障包括 HTTP 429 所表示的繁忙。
允许评估的故障包括网络波动导致上游没有响应。
禁止无差别重试所有异常。
单次模型请求最多重试 2 次，共尝试 3 次。
禁止 SDK 与调用方叠加重试突破这个上限。

补齐缺少的必需提交继续遵守既有任务预算。
这项重试决定不授权重复发送平台消息。

送达后承诺继续使用既有独立恢复机制。

本次删除 Agent Run 的采集、存储与查询能力。
本次删除日志配置、权限声明与后台任务。
本次不增加 DSH 执行日志作为替代。
专用配置表与日志索引表通过迁移退役。
历史 JSONL 文件处置需要单独授权。

普通错误日志、管理审计与安全通知继续保留。
debug 保留安全结果与无业务副作用约束。
依赖 collector 的逐轮明细与用量聚合报告退役。
本次不预建未来日志模块。

本次只为个人助手模式预留改造空间。
个人助手模式留到后续版本实现。

## 取舍

不采用 DSH 回调旧网关的接入方式。
保留旧网关会继续产生自有模型协议适配成本。
采用 DSH 会增加运行时接入与部署责任。
