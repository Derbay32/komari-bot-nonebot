# 共享记忆接收后不随来源群受限而休眠

群准入决定角色能否开展当前群业务。
群受限不代表此前经历失去记忆价值。
记忆接收后，来源群状态不再限制后台整理或跨群使用。

本决策用于计划中的 Hindsight 记忆替换。
本决策尚未落实到生产代码。
本决策不授权生产迁移或部署操作。

## 决策依据

本次记忆迁移设计访谈的 Q19 提出仅替换记忆休眠规则。
Q20 提出将新规则应用于全部已接收记忆。
用户确认：“19和20都通过，按你的建议执行”。

[ADR-0012](0012-unified-group-admission.md) 原先要求受限群记忆休眠。
休眠范围包括召回、索引和后台加工。
Hindsight 的后台处理不读取项目的群准入修订。
自行同步群状态会增加服务端扩展或调度维护。
本决策选择保留 Hindsight 的完整记忆能力。
项目不再维护按来源群休眠记忆的机制。

官方能力依据：

- [记忆提取](https://hindsight.vectorize.io/developer/retain)。
- [观察整合](https://hindsight.vectorize.io/developer/observations)。
- [后台操作](https://hindsight.vectorize.io/developer/api/operations)。

## 记忆边界

- 使用一个共享记忆库。
- 保留现有记忆候选筛选。
- 在接收新记忆候选前检查来源群准入。
- 拒绝接收受限群的新记忆候选。
- 允许 Hindsight 继续处理已接收内容。
- 允许已接收内容继续参与索引和后台维护。
- 允许已接收内容继续形成观察和主题总结。
- 允许共享记忆服务所有获准群成员。
- 允许其他用户触发对共享记忆的召回。
- 禁止按来源群当前状态过滤已接收记忆。
- 保留来源群信息用于追溯。
- 禁止将群禁用解释为记忆删除请求。

新规则覆盖全部已接收内容，包括历史迁入内容。
新规则不限于同一用户跨群使用自己的记忆。
新规则也覆盖已接收但尚未完成提取的内容。
接收确认不等于事实提取完成。
接收确认也不等于内容已经能够召回。

例如，A 群获准时产生一段旅行经历。
Hindsight 接收这段内容后，A 群被设为受限。
Hindsight 仍可整理这段内容。
角色仍可在获准的 B 群使用这段记忆。
角色不能因此向受限的 A 群发送回复。

## 保持有效的约束

- 保留 ADR-0012 的非记忆群准入规则。
- 保留当前触发群的业务准入检查。
- 保留目标群的平台发送准入检查。
- 保留私聊输入限制。
- 保留用户封禁和管理鉴权边界。
- 保留回复履约的发送及既成事实收尾规则。
- 保留近期上下文与长期记忆的区别。
- 保留记忆内容的不可信数据边界。
- 禁止将记忆内容作为系统授权或执行指令。
- 禁止因后台记忆完成而补发旧回复。

独立知识库和其他插件不适用本次替代规则。
新规则不授予来源群之外的任意平台读取权限。
记忆迁移不构成读取生产数据的额外授权。

## 替代范围

ADR-0012 继续保持 accepted 状态。
下列记忆规则以本 ADR 为准：

- 替代已接收记忆随来源群休眠的要求。
- 替代已接收记忆召回时复查来源群的要求。
- 替代已接收记忆后台加工时复查来源群的要求。
- 替代按来源群分区休眠已接收记忆工作的要求。

来源可追溯不再决定已接收记忆的使用资格。
无需把记忆伪装成不可分群派生数据来取得例外。
ADR-0012 对其他可分群混合数据的规则继续有效。

旧记忆运行代码在替换交付前仍保持原有行为。
本决策不声明旧实现已经符合新规则。

## 方案取舍

不采用按群独立建库。
不提供共享与隔离模式切换。
不采用 Hindsight 服务端定制来模拟群休眠。
不采用自有后台整理调度器。
不因来源群撤权而停用自动观察整合。
不因来源群撤权而停用主题总结刷新。

## 接入决策

[ADR-0015](0015-hindsight-memory-replacement.md) 记录已确认的接入决策。
Hindsight 确认接收后，回复不等待后台处理完成。
普通候选不新增本地持久补写队列。
召回失败时停止当前回复。
调用能力恢复后自动恢复聊天。
回复前自动召回和模型按需召回均使用官方 SDK。

禁止在接入细节中恢复已废止的来源群休眠规则。
